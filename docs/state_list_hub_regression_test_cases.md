# 状態一覧ハブ回帰テストケース

## 1. 目的

`bb23641` で改善した状態一覧ハブについて、状態別の案内文、表示ボタン、遷移先、戻り動作が壊れていないかを、毎回同じ観点で手動確認できるようにする。

対象画面:
- `pages/11_状態一覧.py`
- `pages/8_出荷確定.py`
- `pages/9_引当解除.py`
- `pages/10_監査ログ.py`

---

## 2. 共通前提

- ローカルDB: `data/warehouse.db`
- 作業ブランチ: `feat/inventory-transactions-foundation`
- 対象コミット: `bb23641`
- 状態一覧では、詳細確認対象を選ぶと「案内文」「primaryボタン」「secondaryボタン」が表示される
- ボタン表示ルール:
  - primary は 1件のみ
  - secondary は最大 1件
  - その他の導線は表示しない
- 監査ログは状態履歴テーブルとは別画面のため、ボタン表示有無と画面内履歴表示の両方を確認する
- `detail_target` により遷移先へ `order_id` / `line_id` が引き継がれること
- 操作後に状態一覧へ戻る場合は、`return_focus` とフィルタ保持の維持を確認する

---

## 3. 共通確認観点

各ケースで次を確認する。

1. 状態一覧で対象明細を選択できる
2. 状態に応じた案内文が表示される
3. primary / secondary ボタンの表示内容が期待通り
4. ボタン押下で期待ページへ遷移する
5. 遷移先で対象の指示ID / 明細ID が引き継がれる
6. 状態履歴テーブルに「履歴件数」「最新履歴」「メモ短縮表示」が表示される
7. 必要なケースでは、操作後に状態一覧へ戻って `return_focus` が効く
8. 必要なケースでは、絞り込み外になった時の案内文が正しい

## 5. ケース詳細

### SLH-001 `ALLOCATED` / 引当済

#### 目的
- 引当済明細で、状態一覧ハブが「出荷確定」と「引当解除」の両方を次操作として提示できることを確認する。

#### 事前準備
- 対象明細が `ALLOCATED`
- 未出荷数量が残っている
- `hold_flag=0`
- 承認状態が `NOT_REQUIRED` または `APPROVED`

#### 操作手順
1. `pages/11_状態一覧.py` を開く。
2. 対象明細を選択する。
3. 案内文、primary、secondary を確認する。
4. `出荷確定で確認` を押して `pages/8_出荷確定.py` へ遷移する。
5. 対象の指示ID / 明細ID が引き継がれていることを確認する。
6. 状態一覧へ戻る。
7. 再度対象明細を選び、`引当解除で確認` を押して `pages/9_引当解除.py` へ遷移する。
8. 対象の指示ID / 明細ID が引き継がれていることを確認する。

#### 期待結果
- 案内文: `引当済みです。まず出荷確定を確認してください。`
- primary: `出荷確定で確認`
- secondary: `引当解除で確認`
- 監査ログボタンは表示されない
- 状態履歴エリアはエラーなく表示される
- 操作後に戻った場合、フィルタ保持と `return_focus` が維持される

## 6. 戻り導線の重点確認

以下は状態別ケースとは別に、状態一覧ハブ全体として重点確認する。

### RT-001 出荷確定後の戻り
- 対象: `ALLOCATED` または `PARTIAL_SHIPPED`
- 手順:
  1. 状態一覧から `出荷確定で確認` へ進む
  2. 出荷確定を実行する、または保留保存する
  3. `状態一覧で再確認` を押す
- 期待:
  - 成功メッセージが表示される
  - 状態一覧に戻れる
  - `return_focus_message` が表示される
  - 対象明細の状態履歴と導線が確認できる
  - フィルタ保持が壊れない

### RT-002 引当解除後の戻り
- 対象: `ALLOCATED` / `PARTIAL_SHIPPED` / `REALLOC_PENDING` / `HOLD`
- 手順:
  1. 状態一覧から `引当解除で確認` へ進む
  2. 指定数量解除または全解除を実行する
  3. `状態一覧で再確認` を押す
- 期待:
  - 成功メッセージが表示される
  - 状態一覧に戻れる
  - `return_focus_message` が表示される
  - 解除後の状態が確認できる
  - フィルタ保持が壊れない

### RT-003 絞り込み外ケース
- 対象: `return_focus` 確認が必要なケース全般
- 手順:
  1. 操作後に状態一覧へ戻る
  2. 対象明細がヒットしない絞り込み条件を設定する
- 期待:
  - `直前に操作した明細は、現在の絞り込み条件では表示されていません。`
  - `絞り込み条件を変更すると確認できます。`
  - 勝手に別明細へフォーカスしない
